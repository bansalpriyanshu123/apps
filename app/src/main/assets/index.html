कोई हिंदी PDF खोलें

Open a PDF, scroll through it like a normal document, and tap any line to hear it read aloud. If the PDF uses an old Hindi font and the text comes out garbled, Gemini can read the page for you — set it up under ⚙.

Choose a PDF file

Gemini settings

Gemini looks at each page as a picture and returns the real Hindi text — this fixes PDFs made with old fonts (Kruti Dev, Chanakya…) that come out as “%%% 000”, and it also works for scanned PDFs.

Free from aistudio.google.com/apikey. The key is saved only on this device and sent only to Google.
Each page is read once and remembered on this device, so re-opening the same PDF costs nothing.
Default is gemini-3.8-flash. Change only if Google retires it.
When a key is set, Gemini voices (Kore, Puck, Zephyr…) appear in the Voice list. They need internet; device voices work offline.
